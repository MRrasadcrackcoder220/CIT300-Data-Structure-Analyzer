# CIT300 - Data Structure & Graph Performance Analyzer

## Project Description

The Data Structure & Graph Performance Analyzer is a Java-based console application developed for the CIT300 Data Structures and Algorithms Graded Practical Assignment 2.

The system demonstrates the practical implementation of different data structures, searching algorithms, graph operations, traversal algorithms, and performance/complexity comparison.

## Main System Features

The system contains the following components:

1. Array Operations
   - Insert
   - Delete
   - Search
   - Display

2. Stack Operations
   - Push
   - Pop
   - Peek
   - Display

3. Queue Operations
   - Enqueue
   - Dequeue
   - Front / Peek
   - Display

4. Linked List Operations
   - Insert
   - Delete
   - Search
   - Display

5. Searching Operations
   - Linear Search
   - Binary Search

6. Graph Operations
   - Add Vertex
   - Add Edge
   - Display Graph
   - BFS Traversal
   - DFS Traversal

7. Performance Comparison
   - Number of operations / steps
   - Execution information
   - Search results
   - Traversal results

8. Display All Results
